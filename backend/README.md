# Backend

Django MVC application for Sparsh Inclusive Education.

| Path | Purpose |
|------|---------|
| `config/` | Settings, URL routing, WSGI/ASGI |
| `apps/core/` | Home, about, approach, contact, legal |
| `apps/programs/` | Programs & feature pillars |
| `apps/admissions/` | Enquiry form, validation, storage |
| `apps/people/` | Team & advisors |
| `apps/content/` | Testimonials, FAQs, stats, gallery, seed command |
| `media/` | Uploaded files (local development) |
| `manage.py` | Django management commands |

Run from project root: `python manage.py runserver`  
Or from here: `python manage.py runserver`
