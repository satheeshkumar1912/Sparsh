# Frontend

Public website UI for Sparsh Inclusive Education.

| Path | Purpose |
|------|---------|
| `templates/` | Django HTML templates (pages, includes, legal) |
| `static/css/` | Design tokens, layout, components, pages |
| `static/js/` | Navigation, accordion, counters, analytics hooks |
| `static/img/` | Logo, hero, gallery placeholders |

Edit templates and static assets here. Django loads them from `backend/config/settings.py`.
